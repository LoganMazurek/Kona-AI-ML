# Security Policy

## Supported Versions

This repository follows a rolling-release model. Only the latest version on the default branch is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- Email: tparker@kona-ice.com
- Please include a detailed description of the issue, steps to reproduce, and any proof-of-concept code if available.
- You can encrypt sensitive details using our PGP key if one is provided in the future.

We will acknowledge receipt within 3 business days and provide a timeline for remediation once the issue is confirmed.

## Disclosure Policy

We follow responsible disclosure practices. Please do not open public issues for security-related reports.
